# SignalRank AI — Submission Checklist

Track every item before submitting. Each item should be ✅ before sending.

---

## Code and repository

- [ ] `rank.py` runs end-to-end on organizer `candidates.jsonl`
- [ ] Runtime ≤ 5 minutes wall-clock (cold run)
- [ ] No network calls during ranking (confirm with `--no-cache` on clean machine)
- [ ] RAM usage ≤ 16 GB peak
- [ ] All 56 unit + integration tests pass: `python -m pytest tests/ -v`
- [ ] Clean `git status` — no uncommitted work files, no `.env`, no secrets

## Submission CSV

- [ ] File exists: `outputs/submission.csv`
- [ ] Validator passes: `python scripts/validate_submission.py outputs/submission.csv`
- [ ] Exactly 100 data rows (101 lines including header)
- [ ] Ranks 1–100 each appear exactly once
- [ ] `score` column is monotonically non-increasing
- [ ] All `candidate_id` values present in `candidates.jsonl`
- [ ] Encoding is UTF-8
- [ ] Reasoning field is populated for all 100 rows

## Evaluation

- [ ] `outputs/debug.json` generated with `--json` flag
- [ ] `outputs/eval_report.json` generated by `evaluation/eval.py`
- [ ] Zero honeypots in top-100 (check eval report)
- [ ] Top-10 ML/AI fraction ≥ 70% (check eval report)
- [ ] No systematic errors detected (check error_detection section)
- [ ] Baseline comparison: meaningful differentiation from keyword model

## Submission metadata

- [ ] `submission_metadata.yaml` filled with correct team info
- [ ] `github_repo` URL is correct and public
- [ ] `sandbox_link` is accessible (Streamlit Cloud or HuggingFace Spaces)
- [ ] `reproduce_command` runs correctly from a clean clone
- [ ] `methodology_summary` accurately describes the approach
- [ ] All declarations are `true`

## Documentation

- [ ] `README.md` up-to-date (setup, run, evaluate, structure)
- [ ] `docs/architecture.md` describes pipeline and design decisions
- [ ] `docs/deployment.md` covers setup, tuning, environment notes
- [ ] `docs/evaluation_report.md` covers methodology and results
- [ ] `docs/user_guide.md` covers the Streamlit dashboard

## Demo

- [ ] Streamlit dashboard runs: `streamlit run app/streamlit_app.py`
- [ ] All 4 tabs load without errors
- [ ] Upload → Rank Candidates → results display correctly
- [ ] Candidate detail panel shows full breakdown
- [ ] Download buttons work (CSV, JSON)
- [ ] Eval tab loads evaluation report correctly

## Final checks

- [ ] Reproduce from clean clone:
  ```bash
  git clone <repo> && cd signalrank-ai
  python3 -m venv .venv && source .venv/bin/activate
  pip install -r requirements.txt
  python rank.py --candidates candidates.jsonl --out submission.csv
  python scripts/validate_submission.py submission.csv
  ```
- [ ] Score of top-1 candidate > 0.85
- [ ] No honeypots in top-10
- [ ] Reasoning is readable and evidence-grounded (not vague)
- [ ] Pitch deck reviewed for accuracy
